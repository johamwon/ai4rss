How River keeps reading local-first

River displays trustworthy feed content before making any additional request. When a source provides only a summary, the client can progressively enrich the page without delaying the first useful reading state or giving up local control.

The extraction pipeline ranks candidate blocks by structure, punctuation, text length, and link density. Navigation lists and promotional sidebars should not outrank several coherent paragraphs that explain one subject in detail.

A reader should see the article, not the furniture around it.

The normalized result keeps useful structures such as code, quotations, tables, and images. Every fragment still crosses the shared sanitizer before the application stores or renders it.
