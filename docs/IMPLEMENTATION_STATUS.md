- TTS-004 核心：进程级共享播放控制器接入统一 `AudioSystemSession`，Android/iOS 通过固定版本的 `audio_service` 与 `audio_session` 提供后台服务、通知/锁屏、耳机命令、音频焦点、中断和拔耳机事件；Windows 由仓库内 C++/WinRT `SystemMediaTransportControls` 适配器提供系统媒体控制。只有中断前正在播放且系统明确许可时才能自动恢复，拔耳机只暂停。Windows Debug 原生编译、Runner 测试、隐藏启动 Smoke 和真实 SMTC MethodChannel Integration Test 已通过；Android/iOS 注册已纳入 CI 构建验证。
- TTS-005 核心：供应商无关的语音段预取管线使用代次取消、当前段加三个前瞻段、最多两个并发任务和默认 8 MiB 保留预算；文章、段落或完整音色设置变化会取消旧代次并释放窗口外资源，忽略取消的后端晚返回时也会立即释放。预取错误只进入稳定降级态，不改变系统 TTS 播放；停止、最终完成、替换加载和控制器关闭均清理资源。108,000 字符合成两小时长文的分段计划估算低于 2 MiB，并在五秒门槛内完成。Free 系统 TTS 保持零额外预取资源，阶段 12 云 TTS 可通过同一接口注入计费缓存后端。
- SYNC-001 核心：定义协议 v1 的账户、设备、公钥、数据密钥描述、逐设备密钥包装、密文信封、墓碑、游标、推拉批次和六类同步对象；密文元数据绑定稳定 AEAD Associated Data，限制 1 MiB 信封与 200 条批次。逐设备版本向量区分因果、相等与并发更新，冲突模型固定各对象的字段 LWW、语义合并、最远进度及墓碑优先级；服务器序号只控制投递，不参与因果判断。威胁模型明确服务端不可读、元数据泄露、设备撤销后轮换和无法服务端找回的边界。
- SYNC-002 核心：定义无密码邮箱挑战、脱敏证明与令牌、安全会话仓库、远端身份网关、设备注册、待审批加入、设备列表和撤销端口。首设备激活，后续设备只能轮询审批状态，既有设备必须提交账户/发送方/接收方完全匹配的包装数据密钥；登录完成以幂等键防重复设备。每次云同步前远端刷新设备授权；离线不清会话，服务端判定会话过期或设备撤销才清安全会话，退出不删本地内容。撤销要求数据密钥轮换，最后一个活跃设备受保护。
- SYNC-003 核心：固定 `cryptography` 2.9.0 实现 AES-256-GCM 密文信封、X25519 临时密钥协商、HKDF-SHA-256 数据密钥包装、轮换和 256 位恢复码；账户/对象/版本向量等元数据全部进入 AEAD Associated Data。私钥、数据密钥和恢复码可脱敏并尽力销毁。`flutter_secure_storage` 10.3.1 适配器在 Android 使用 API 23+ Keystore 且禁用备份、iOS 使用仅本机 Keychain、Windows 使用 DPAPI 并串行化访问；损坏/未来 Schema 不静默删除。恢复提示必须确认离线保存，服务端无法找回。
- SYNC-004 核心：六类同步对象使用显式、定界且不含正文/凭据的 v1 明文载荷，经 SYNC-003 加密后进入持久 outbox；完整确认后才删除。增量状态机按最多 200 条分页推拉，整页解密校验后将接收记录、冲突与 opaque cursor 在同一事务提交；离线、部分确认、非前进游标、错误载荷和事务失败均保留可重试状态。Drift v6 持久化当前副本、outbox、逐设备游标和冲突队列并支持中断迁移恢复；双设备六类型往返、72 次随机离线编辑及重启恢复已覆盖。
- SYNC-005 核心：upsert 字段携带 UTC/设备/mutation 版本并兼容无字段版本的旧载荷；订阅、文件夹和知识元数据使用字段 LWW，阅读状态执行单调语义合并，设置执行确定性记录 LWW，同版本音频保留最远断点。并发墓碑按对象策略取舍，真实合并产生加密派生 mutation。Drift v7 在同一事务写入副本、冲突决议审计、seen-mutation 与可选 outbox；完全相同的重放幂等，不同密文复用 mutation ID 时拒绝整页且不推进游标。墓碑至少保留 30 天且仅在所有活跃设备游标越过后可压缩；并发、乱序、重复、同钟、旧载荷和离线一周均有自动测试。
- SYNC-006 核心：纯 Dart 账号体验控制器统一会话恢复、持久同步状态、失败分类、显式重试与有界冲突历史；Drift 仓库按设备统计 outbox/cursor、按账号统计未决冲突并返回最新决议记录。Flutter 三端共用同步与账号页，展示状态、待上传数、冲突历史和游标。退出仅清安全会话并保留全部本地内容；云端删除是独立网关操作，必须收到同账号完成回执才清会话，UI 还要求输入精确确认短语。云适配器通过可选依赖注入启用入口，本地版不受云不可用影响。
- SYNC-007 核心：服务端内核仅接收 E2EE 信封与有界路由元数据，不持有数据密钥或明文解码入口；活跃设备授权、多租户隔离、逐设备 UTC 窗口限流、原子字节/条目配额、精确幂等与 mutation 碰撞拒绝均在存储前后封闭。管理员只可读取条目数、编码字节和最新序号，审计不含信封、密文、令牌或密钥。备份以账号绑定的 SHA-256 校验保护有序密文，恢复校验账号与 mutation 唯一性；灾演在隔离仓库恢复并只报告计数/字节/序号。云删除仅删除密文账号记录并返回同账号完成回执。
- POD-001 核心：纯 Dart Podcast RSS 解析器提取节目/分集、enclosure、相对 URL、封面、作者、日期、时长、季/集号、类型和显式标记；只接受无凭据的 HTTP(S) 音频，异常可选字段安全降级。刷新服务使用 ETag/Last-Modified 增量请求，同一文档按外部身份去重；GUID 是首选稳定身份，同 GUID 换媒体 URL 时保留 River ID 并只 upsert 变化分集，完全相同的分集不重写。节目级默认倍速与下载策略作为后续播放/持久化的稳定契约。
- 首个纵向切片：添加 Feed URL → 下载 → 解析 → SQLite 幂等写入 → 订阅及文章列表。
- Windows Debug 构建和真实 Runner Integration Test。
